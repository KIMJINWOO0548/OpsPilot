# OpsPilot-X · 합성 40건 비교 결과

겹치지 않는 10개 IT 문서군에서 개발 24건과 홀드아웃 16건을 한 번씩 실행했다. 동일한 Qwen 생성 모델, 구조 제약, 상위 4개 근거, 응답 한도로 비교했다. 단순 RAG는 고정 합성 파일에서 단어 겹침으로 검색하며 권한·두 시점·충돌 검사를 적용하지 않는다.

모델 전달은 실제 임베딩 배치와 생성 입력에 담긴 근거 ID를 기록한다. 시점 오류는 응답에 실린 유효 기간 위반, 관측 전 버전, 대체된 버전의 합집합이다. 서로 다른 지표의 분자는 겹칠 수 있다. 인용 지표는 실제 조치가 반환된 응답만 분모에 넣고, 정답률과 초안 제시율은 모든 적격 사례를 분모에 넣는다. 같은 생성기가 인용 1개를 제약하므로 인용 지표는 원문과 해당 조치를 뒷받침하는 자료의 일치가 중심이다.

고정 합성 예비 실험이다. 성능 벤치마크와 운영 안전성을 일반화할 수 없다. 케이스당 후보가 4개 이하이므로 BM25와 임베딩의 독립적인 품질 개선은 이 실험에서 측정하지 않았다.
