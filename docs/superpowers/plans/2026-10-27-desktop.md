# Windows Desktop 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 기존 안전 정책을 유지하는 Windows 전용 앱과 사용자별 설치형 배포본을 만든다.
**Architecture:** WPF/WebView2 호스트가 bundle Python의 FastAPI를 loopback 임의 포트에서 관리한다. UI는 기존 React build를 재사용하고 native 최초 설정·오류 복구와 per-user installer를 제공한다.
**Tech Stack:** .NET10/WPF, cached WebView2 1.0.4258.31, Python3.12, FastAPI/SQLite, 기존 React/TS.
**Spec:** `docs/superpowers/specs/2026-10-27-desktop-design.md`

## Global Constraints

- Windows11 x64, loopback only, mock only. 기존 session/CSRF/SQL ACL·승인·해시·멱등성 보존.
- 새 다운로드/전역 설정/실계정 변경/공개 배포 금지. offline restore는 기존 캐시만 사용.
- 앱·설치기는 asInvoker, unsigned preview. DB는 `%LocalAppData%/OpsPilot-X`, 설치는 `%LocalAppData%/Programs/OpsPilot-X/<version>`.
- 기존 저장소 DB/volume·`.local`·사용자 쿠키·비밀번호는 배포본에 포함하지 않음.
- `.git` 없음: commit/PR 단계 대신 파일/검증 로그 기록.

## Review Focus

- 변조된 readiness/Host/토큰으로 다른 로컬 프로세스를 앱 서버로 오인하지 않음.
- 초기 설정은 빈 users일 때만 두 계정 원자 생성, 실패 시 부분 생성 없음.
- 앱 crash/종료 뒤 소유 API listener를 남기지 않음.
- 패키지 경로 순회·재분석 지점·변조 파일·기존 설치 덮어쓰기를 거부.
- 설치/제거·업데이트가 사용자의 DB를 지우거나 교체하지 않음.

## 공통 인터페이스

배포: `OpsPilot-X.exe`, `backend/python/python.exe`, `backend/python/Lib/site-packages/opspilot_x`, `backend/web/dist`, `licenses`, `release-manifest.json`.

호스트가 Python을 `-I -u -m opspilot_x.desktop_runtime --data-dir <absolute> --web-dir <absolute>`로 시작. stdin 첫 줄 JSON `{"token":"64 lowercase hex"}`. stdout `{"event":"setup_required"}` 또는 `{"event":"ready","origin":"http://127.0.0.1:<port>","token":"..."}`. stderr는 비밀 없는 제한된 진단. 설정 필요 시 stdin 다음 줄 `{"engineer":{"username":"...","password":"..."},"approver":{...}}`; 성공 뒤 ready, 실패 시 `{"event":"setup_error","message":"..."}` 후 재입력 가능. stdin EOF/`{"event":"stop"}`은 graceful stop. HTTP는 `X-OpsPilot-Desktop-Token`과 정확한 Host를 필수로 요구하며 사용자 로그인은 별도다.
