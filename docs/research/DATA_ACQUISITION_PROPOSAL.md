# 외부 데이터·모델 실행 전 승인 범위 초안

2026-10-20. 현재 외부 데이터와 모델 가중치는 다운로드하지 않았고 유료 모델 호출도 실행하지 않았다.

다음 연구 단계에 제안하는 최소 범위는 **공식 출처 1종, 최대 30개 질문과 필요한 문서 버전 30개, 저장량 상한 256 MiB**다. 이는 아직 특정 원천으로 실행해 측정한 크기가 아니라 초과 시 중단할 제한값이다. source/revision family로 분리하고 실제 확보 가능한 독립 group 수를 먼저 확인한다. 30문항을 대규모 성능 평가로 부르지 않는다.

| 확인/승인 항목 | 현재 상태 |
|---|---|
| 원천 | EnterpriseRAG-Bench T1 또는 권리가 명시된 T2 원문 후보. 선택 미확정 |
| 공식 코드 | prior_art_matrix.csv에 commit·코드 LICENSE 기록. 데이터 권리와 구별 |
| 데이터 권리 | 원문/질문/정답별 로컬 저장·평가·파생·인용·재배포 범위 미확인. 범위가 불명확하면 실행하지 않음 |
| 사람 검토 | T2 작성자와 다른 검토자 2인 확보 필요. 아직 미확보 |
| 데이터 준비의 모델 API 예산 | 0 USD. 자동 정답 생성·유료 호출 없음 |
| 모델 비교 비용 | 모델/provider와 토큰량 미선정이므로 미측정. 호출 전에 입력/출력 토큰·질문 수·가격·상한을 별도 제시 |
| 외부 업로드/실계정/실업무 쓰기 | 이번 제안에 포함하지 않음. 작업 실행은 로컬 mock만 |

승인 전에 자산명·정확한 URL·고정 버전·LICENSE/사용 허락 원문과 위 제한값을 특정해야 한다. 이 초안은 사용 권리 확인이나 다운로드 승인을 받았다는 뜻이 아니다. 사용자 승인이 있더라도 명시된 조건을 위반하는 배포/모델 가중치 사용을 허용하는 것으로 해석하지 않는다.
